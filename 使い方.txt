顔人数・上半身フィルターの使い方
==================================

顔検出にYuNet、人物／上半身の検出に同梱のYOLOv8nを使います。
顔が1人で、人物が1人検出され、人物の高さが画像の35%以上で、顔の下に上半身が続いている画像だけを残します。
顔なし、顔が複数、人物が複数、顔アップ、人物が小さすぎる画像は削除候補です。

初回だけの準備
--------------
Python 3.10以降が必要です。OpenCV 5以降・Ultralytics・PyTorchをプロジェクト内の仮想環境へインストールします。
このフォルダでコマンドプロンプトを開き、次を実行してください。

   python -m venv .venv
   .venv\Scripts\python.exe -m pip install --cache-dir .pip-cache -r requirements.txt

PyTorchを含むため、初回のインストールには時間とディスク容量が必要です。

使い方（おすすめ）
------------------
1. 画像フォルダをエクスプローラーで開きます。
2. 画像フォルダを、このフォルダ内の run.bat にドラッグ＆ドロップします。
3. 削除予定数と理由別の件数を確認します。
4. よければ y を入力します。n または Enter なら削除しません。

run.bat をダブルクリックした場合は、フォルダ選択画面が開きます。通常は選択フォルダ直下だけを処理します。

サブフォルダもまとめて処理する場合は、コマンドで次のように指定します。

   .venv\Scripts\python.exe fp.py "画像フォルダのパス" --recursive --min-person-height 0.35

再帰処理でも、確認画面に削除予定数を表示し、yを入力した場合だけ削除します。

判定について
------------
- YuNetで顔の人数を判定し、YOLOv8nの人物検出枠が顔の下へ十分続く場合に「胸元まで写っている」と判定します。
- 画像の胸部そのものを直接識別しているわけではありません。顔／人物の検出モデルによる推定のため、誤判定はあり得ます。
- 人物検出は一般物体検出（COCO personクラス）です。人物の高さが画像の35%未満なら「小さすぎる」として削除候補になります。小さな人物や大きな遮蔽は見逃し／誤判定の可能性があります。
- 最低サイズを変更する場合は、例として `--min-person-height 0.4` のように指定します（画像高さの40%）。値を上げるほど大きく写った人物だけ残ります。
- 処理対象は選択フォルダ直下の画像だけです。サブフォルダは処理しません。
- 読み込み・推論エラーの画像は削除せず残します。
- yで実行した削除はごみ箱を経由せず完全削除されます。実行前にバックアップを取ってください。
